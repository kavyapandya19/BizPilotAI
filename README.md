# BizPilot AI

BizPilot AI is an autonomous AI-powered business management platform that transforms raw business data into insights, predictions, recommendations, and automated actions through an intelligent AI agent.

## Architecture

- **Frontend:** React + Vite
- **Backend:** Node.js + Express
- **ML Service:** Python + FastAPI
- **Database:** MongoDB
